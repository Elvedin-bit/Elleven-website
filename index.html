Over mij

Techneut met een no-nonsense aanpak.

Ik ben Elvedin — freelance webdesigner en automatiseringsspecialist uit Antwerpen. Technologie fascineert me, vooral hoe ze processen kan versnellen. Dat vertaal ik naar websites die niet alleen mooi ogen, maar ook razendsnel laden en écht converteren.

Geen eindeloze vergaderingen, geen vage rapporten. Ik lever wat ik beloof, op tijd, en met code waar je op kan bouwen — vandaag én over drie jaar.
